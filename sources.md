# Source whitelist

Ranked. Higher = more authoritative. Agents must cite at least 4 sources per `research.md`, and at least 2 of those must be Tier 1.

## Tier 1 — authoritative

| Source | Domain | Use for |
|---|---|---|
| Wikipedia (English) | en.wikipedia.org | dates, platforms, developers, release info |
| MobyGames | mobygames.com | credits, platforms, release dates |
| Hardcore Gaming 101 | hardcoregaming101.net | mechanism deep-dives, lineage |
| The Digital Antiquarian (Jimmy Maher) | filfre.net | 1980s home computer history |
| GDC Vault | gdcvault.com | developer talks on specific mechanics |
| Game Maker's Toolkit (Mark Brown) | youtube.com/@GMTK | mechanic analysis (cite with timestamp) |
| Game Developer / Gamasutra archives | gamedeveloper.com | postmortems, technical articles |
| Shmuplations | shmuplations.com | translated Japanese developer interviews |
| Retro Gamer magazine archives | retrogamer.net (where free) | period coverage |
| Polygon, RPS, Eurogamer long-form retrospectives | various | designer interviews |

## Tier 2 — useful, verify

| Source | Domain | Caveat |
|---|---|---|
| GiantBomb concepts | giantbomb.com | community-edited, verify facts |
| TVTropes | tvtropes.org | use for *naming* primitives, not facts |
| Sega Retro | segaretro.org | strong on Sega platforms |
| NESdev wiki | nesdev.org | technical, not design |
| C64 Wiki | c64-wiki.com | platform-specific |
| Lemon64 | lemon64.com | C64 game database |
| World of Spectrum | worldofspectrum.org | ZX Spectrum |
| The CRPG Addict | crpgaddict.blogspot.com | RPG mechanism deep dives |
| Matt Chat (YouTube) | youtube.com/@MattChat | developer interviews |
| DiGRA proceedings | digra.org | academic, formal game studies |
| Game Studies journal | gamestudies.org | academic |
| Mark Brown GMTK transcripts (fan-made) | various | use as lead, verify against video |

## Tier 3 — community, treat as leads

- r/truegaming, r/gamedesign — discussion, not citation
- TIGSource forums — indie mechanic prototypes
- Glorious Trainwrecks — experimental small games
- itch.io devlogs — primary source if author writes about own game
- Pico-8 BBS notes — designer notes on tiny games
- IndieDB — lead for indie mechanics
- Steam community guides — gameplay only, no historical claims

## Tier 4 — avoid as primary

- AI-generated listicles
- "Top 10 X games" content farms
- Fan wikis without inline citations
- Reddit comments (except where author identifies as developer with proof)
- Tier-A YouTubers without research-quality production (entertainment, not history)

## Hard exclusions
- AI-summary aggregators (always cite the primary source they pull from)

## Citation date
Every URL citation includes `retrieved YYYY-MM-DD`. Sources may change; the retrieval date pins what we saw.
